# Lucid
A completely free dream journal for Android, no ads, fully local.

## Download
Get the latest APK from [Releases](link).

## Features
- Dream journal with mood, vividness, and tags
- Streak tracking
- Analytics showing what actually improves your recall
- Reality check reminders
- WBTB alarm

## Build from source
1. Clone the repo
2. npm install
3. npx expo run:android
